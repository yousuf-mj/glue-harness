# 0001: GitHub holds no company content

**Context.** The core of the harness lives in my personal GitHub so it can be shared between my personal and work setups. Work done at work, and anything about its people, systems or customers, may belong to the company and must stay within it.

**Decision.** The `harness` repo holds only core skills and profile adapters that would make sense at any company. All my employer-specific knowledge, learnings and rules live in work Glue on the work laptop. Promotions from work to core need their own approval and a scrub check. The core never goes into my employer's GitLab.

**Consequences.** Company knowledge doesn't follow me across setups. That's intended. Some useful rules stay local. Before any push I search for company terms.
