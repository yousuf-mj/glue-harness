# References for the writing skill

| Key | Source | Use |
|---|---|---|
| MS-PROC | [Microsoft Style Guide: Procedures and instructions](https://learn.microsoft.com/en-us/style-guide/procedures-instructions/) | Base authority. The best procedure is one the user doesn't need |
| MS-STEP | [Microsoft: Writing step-by-step instructions](https://learn.microsoft.com/en-us/style-guide/procedures-instructions/writing-step-by-step-instructions) | Numbered steps, imperative verb, one action per step, location before action |
| MS-UI | [Microsoft: Describing interactions with UI](https://learn.microsoft.com/en-us/style-guide/procedures-instructions/describing-interactions-with-ui) | Verb map: select, go to, enter, turn on/off, clear |
| MS-FMT | [Microsoft: Formatting text in instructions](https://learn.microsoft.com/en-us/style-guide/procedures-instructions/formatting-text-in-instructions) | One consistent way of referring to labels |
| MS-A11Y | [Microsoft: Writing for all abilities](https://learn.microsoft.com/en-us/style-guide/accessibility/writing-all-abilities) | No directional words as the only clue |
| MS-GLOBAL | [Microsoft: Global writing tips](https://learn.microsoft.com/en-us/style-guide/global-communications/writing-tips) | Short, literal sentences |
| GOOGLE | [Google developer style: Procedures](https://developers.google.com/style/procedures) | Goal before action, result in the same step, "Optional:", no "please" |
| GOV-CLEAR | [GOV.UK: Use clear language](https://guidance.publishing.service.gov.uk/writing-to-gov-uk-standards/writing-guidelines/clear-language/) | 25-word sentences, 5-sentence paragraphs, must / need / can |
| DIAT | [Diátaxis compass](https://diataxis.fr/compass/) | Tutorial, how-to, reference, explanation; keep them apart |
| MIN | [Minimalism in documentation (Carroll, van der Meij), summary](https://www.psy.gla.ac.uk/~steve/MinMan2.html) | Error recovery inside the steps |
| GITLAB | [GitLab docs: Troubleshooting topic type](https://docs.gitlab.com/development/documentation/topic_types/troubleshooting/) | Title is the error; when, cause, fix; warn before data changes |
| COK | [Camerer, Loewenstein & Weber 1989, curse of knowledge](https://www.cmu.edu/dietrich/sds/docs/loewenstein/CurseknowledgeEconSet.pdf) | Authors can't easily un-know what they know |
| EBS | [Nathan et al. 2001, expert blind spot](https://website.education.wisc.edu/~mnathan/Publications_files/2001_NathanEtAl_ICCS_EBS.pdf) | Experts skip steps novices need |
| NNG-FC | [NN/g: False-consensus effect](https://www.nngroup.com/articles/false-consensus/) | You are not the user |
| PERSONA | [Zheng et al., EMNLP 2024](https://aclanthology.org/2024.findings-emnlp.888/) | Expert personas don't improve accuracy; references and checklists do |
| MC-VT | [Mailchimp Content Style Guide: Voice and tone](https://styleguide.mailchimp.com/voice-and-tone/) | Voice stays the same; tone changes with the situation and the reader |
| NNG-TONE | [NN/g: The four dimensions of tone of voice](https://www.nngroup.com/articles/tone-of-voice-dimensions/) | Tone as a set of dials (funny–serious, formal–casual, respectful–irreverent, enthusiastic–matter-of-fact) |
| QUOTE | [Claude docs: reduce hallucinations](https://platform.claude.com/docs/en/test-and-evaluate/strengthen-guardrails/reduce-hallucinations) | Quote the text, cite the rule, retract unsupported claims |

Unverified figures to keep out: GOV.UK "reading age of 9" and BDA "60 to 70 characters" (not confirmed in our research).
