# Tone: neutral

For: team updates, how-tos, tutorials, reference pages, runbooks, explanations.

- **Shape:** the section 2 layout (summary first, decisions and actions at the end) and the shape for the doc type.
- **Person:** "we" for the team, "you" for the reader.
- **Contractions:** fine, except negative ones in instructions (write "do not", not "don't") so a skimmed step can't be misread.
- **Voice:** plain and friendly. Leave out the chatty words from the voice file ("cool", "no worries").
- **No** greeting or sign-off unless the doc is sent as a message, then use the voice file's.
- **No** emojis or exclamation marks.
