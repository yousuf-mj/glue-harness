# Glue (work)

- `inbox.md`: quick captures not filed yet
- `learnings.md`: one line per learning (see below)
- `standing-rules.md`: approved company rules, loaded every session
- `projects/<slug>/`: a piece of work (docs, decisions.md, notes)
- `areas/`: ongoing responsibilities (team, 1:1s, hiring, on-call)
- `resources/`: reference (systems, `people/` profiles, how-tos)
- `archive/`: finished projects

Learning line:
`- YYYY-MM-DD | <skill> | correction|note|estimate | <what happened> → <what I wanted> | why: <reason> | count: 1`
Estimates add `est: <time> actual: <time>`.

Nothing in this folder goes to GitHub.
