# Glossary

- **Core:** the shared skills and files in the `harness` repo that know nothing about where they run or which company they're used at.
- **Profile:** a small plugin whose skill `profile-<name>` that tells the core where Glue lives, where docs are published and who signs off. One per setup: work, personal.
- **Glue:** the place where state goes (projects, decisions, learnings). The name of a role, not a tool. Personal Glue is an artifact. Work Glue is the folder `~/glue/`.
- **Learning:** one line in `learnings.md` recording a correction, a note or an estimate against its actual.
- **Standing rule:** a learning that repeated and was approved. It applies to every future run of that setup.
- **Promotion:** moving a learning up a level: learning → standing rule (local), or standing rule → core change (GitHub, needs its own approval and a scrub check).
- **Boundary rule:** something may go to GitHub only if it would make sense at any company.
- **`me` (skill):** how I like to work and read, shared by every profile.

## Work vocabulary (standing rule)
Jira-style names replace the personal, themed ones:
- **project** (was realm)
- **epic** (was saga)
- **ticket** (was quest)
No playful or themed wording in skills.
